Comment créer un tunnel de vente avec systeme.io ?

Les 4 types de tunnels, l'ordre des pages et la façon de les relier entre elles.

Par Dario PinheiroMis à jour le 4 oct. 2026

Un tunnel de vente est une suite de pages qui mène le visiteur vers une seule action : s'inscrire, puis acheter. Dans systeme.io, il remplace à la fois l'outil de landing pages et la page de paiement.

Pour suivre ce guide, il vous faut un compte systeme.io : le plan gratuit ne demande pas de carte bancaire.

Créer un compte gratuit systeme.io ↗Lien affilié : si vous créez un compte via ce lien, je touche une commission, sans surcoût pour vous.

L'essentiel en 30 secondes

  1. Créez le tunnel
  2. Choisissez le bon type
  3. Ajoutez les pages qui manquent
  4. Respectez l'ordre des pages
  5. Reliez les pages entre elles
  6. Activez les paiements et testez

À éviter : Placer l'upsell avant la page de paiement : il doit venir juste après.

Étape par étape

  1. 1.Créez le tunnel

    Allez dans l'onglet « Sites », puis « Tunnels de vente », et cliquez sur « Créer ». Donnez un nom au tunnel, choisissez le nom de domaine à utiliser et la devise.

  2. 2.Choisissez le bon type

    « Créer une audience » crée une page de capture et une page de remerciement : idéal pour récolter des e-mails. « Vendre » crée une page de paiement et une page de remerciement. « Créer un tunnel personnalisé » part de zéro. « Créer un webinaire automatique » crée un tunnel de 3 pages, seulement sur les plans Webinaire et Illimité.

  1. 3.Ajoutez les pages qui manquent

    Dans le menu de gauche du tunnel, cliquez sur « Ajouter une étape », donnez un nom, choisissez le type (page de capture, page de vente, page de paiement, upsell, downsell, page de remerciement…), puis un modèle. Cliquez sur « Modifier la page » pour la personnaliser.

  2. 4.Respectez l'ordre des pages

    L'ordre type est : page de capture, page de vente, page de paiement, upsell, downsell, page de remerciement. L'aide officielle précise que les pages doivent respecter cet ordre pour que le tunnel fonctionne.

  3. 5.Reliez les pages entre elles

    Sur la page de capture, réglez l'action du bouton sur « Enregistrer le contact » et la redirection « Vers l'étape suivante du tunnel ». Sur la page de vente, réglez le bouton sur « Rediriger vers une page » avec l'adresse de la page de paiement. Après le paiement, la suite (upsell, downsell, remerciement) s'enchaîne automatiquement.

  4. 6.Activez les paiements et testez

    Dans les « Paramètres » du tunnel, cochez « Carte de crédit ou de débit (Stripe) » et/ou « PayPal », puis « Sauvegarder » (les comptes doivent être connectés avant). Parcourez ensuite tout le tunnel vous-même, comme un client.

    Erreurs fréquentes

    • Placer l'upsell avant la page de paiement : il doit venir juste après.
    • Oublier d'activer Stripe ou PayPal dans les paramètres du tunnel, même si les comptes sont connectés.
    • Sur le plan gratuit, oublier la limite de 3 tunnels et 15 étapes au total.
